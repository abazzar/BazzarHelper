# 大巴扎助手 / BazzarHelper

大巴扎助手是《The Bazaar》的桌面战绩记录插件。它会在本机读取游戏战绩，并同步到微信小程序，方便回看和分享每局战斗。

官方下载页：[bazzarhelper.com](https://bazzarhelper.com/)

## 下载

安装包与版本更新在 [Releases](https://github.com/abazzar/BazzarHelper/releases) 发布。

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| macOS | Apple Silicon / ARM64 | `.dmg` |
| Windows | x64 | `.exe` |

当前版本为 `0.1.0`。请从对应版本的 Release 下载适合自己系统的安装包，并在下载完成后核对 Release 中提供的 SHA-256。

## 使用方式

1. 下载并安装桌面客户端。
2. 安装引导会帮助你配置游戏插件。
3. 使用微信或 QQ 扫码登录。
4. 打开微信小程序即可查看同步后的战绩与 PvP 战斗详情。
